## 3. Реализация

### 3.1. Шаблонный класс Pair<T1, T2>

    template <typename T1, typename T2>
    class Pair {
    private:
        T1 first_;
        T2 second_;

    public:
        Pair() : first_(), second_() {}

        Pair(const T1& first, const T2& second)
            : first_(first), second_(second) {}

        Pair(const Pair&) = default;

        T1 getFirst()  const { return first_;  }
        T2 getSecond() const { return second_; }

        void setFirst(const T1& value)  { first_  = value; }
        void setSecond(const T2& value) { second_ = value; }

        void print() const {
            std::cout << "(" << first_ << ", " << second_ << ")";
        }
    };

### 3.2. Демонстрация (фрагмент main.cpp)

    int main() {
        Pair<int, std::string> p1(42, "ответ");
        p1.print(); std::cout << "\n";

        p1.setFirst(100);
        p1.setSecond("изменено");
        p1.print(); std::cout << "\n";

        Pair<double, char> p2(3.14, 'A');
        p2.print(); std::cout << "\n";

        Pair<int, int> inner(1, 2);
        Pair<std::string, Pair<int,int>> p3("точка", inner);
        // ... вывод
    }

## 4. Анализ сложности операций

| Операция | Сложность | Обоснование |
|---|---|---|
| Конструктор по умолчанию | O(1) | инициализация двух полей |
| Конструктор с параметрами | O(1) | копирование двух значений |
| Конструктор копирования | O(1) | копирование двух полей |
| getFirst() | O(1) | возврат одного поля |
| getSecond() | O(1) | возврат одного поля |
| setFirst() | O(1) | присваивание одного поля |
| setSecond() | O(1) | присваивание одного поля |

> **Замечание.** Сложность указана для типов фиксированного размера (int, double, char).  
> Для типов переменного размера (std::string) копирование в конструкторе/сеттере даёт O(k), где k — размер значения.

## 6. Контрольные вопросы

### 1. Что такое О-нотация и зачем она нужна?

Математическая запись асимптотической сложности: f(n) = O(g(n)), если ∃ c > 0, n₀ : 0 ≤ f(n) ≤ c·g(n) для всех n ≥ n₀. Позволяет сравнивать алгоритмы независимо от констант и железа.

### 2. Сложность доступа к элементу массива по индексу?

O(1) — адрес вычисляется как base + i·sizeof(T).

### 3. Сложность бинарного поиска?

O(log n) — на каждом шаге область поиска уменьшается вдвое.

### 4. Что означает O(n log n)?

Комбинация линейного прохода и логарифмического деления. Пример — сортировка слиянием, быстрая сортировка.

### 5. Что такое амортизированный анализ?

Усреднение стоимости операции за серию вызовов. Пример — push_back в std::vector: отдельный вызов O(n), амортизированно O(1).

### 6. Сложность двух вложенных циклов по n?

O(n²).

### 7. Сложность рекурсивного Фибоначчи?

O(2ⁿ) — экспоненциальная (без мемоизации).

### 8. Что такое шаблоны функций?

Обобщённые функции с параметром-типом: template <typename T> T max(T a, T b);.

### 9. Что такое шаблоны классов?

Классы, параметризованные типами: template <typename T> class Stack { ... };.

### 10. Преимущество шаблонов перед перегрузкой?

Нет дублирования кода; компилятор генерирует нужные версии автоматически.

### 11. Как указать, что параметр — тип?

template <typename T> или template <class T>.

### 12. Можно ли создать шаблон с несколькими параметрами?

Да: template <typename T1, typename T2> class Pair;.

### 13. Как измерить время выполнения?

std::chrono::high_resolution_clock::now() до и после операции.

### 14. Почему операцию нужно повторять многократно?

Точность таймера ограничена; единичный замер может быть меньше разрешения таймера.

### 15. Что важнее — сложность или константа?

Для больших n — сложность; для малых — константа (например, сортировка вставками быстрее для малых массивов).
